> Ce projet est un **exercice académique / de portfolio** réalisé dans le cadre d’une démarche personnelle et d’une entrevue.

## Objectif du projet

Ce dépôt présente une étude de cas fictive portant sur un plan stratégique commercial dans le secteur de la réparation et du remplacement de verre automobile. L’objectif est de démontrer des compétences en :

- analyse stratégique ;
- élaboration de recommandations commerciales ;
- structuration de présentations professionnelles ;
- utilisation d’outils de visualisation et de documentation.

## Statut et affiliation
